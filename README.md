# ML-скрининг нетоксичных неорганических магнитных оксидов

Вычислительный пайплайн для предварительного отбора неорганических оксидов по химическому составу и 3D-структуре кристаллической решётки с целью поиска вероятно магнитно-упорядоченных и нетоксичных фаз для приоритизации синтеза.

> **Важное примечание о данных:** Все целевые метки магнитного упорядочения (`FM`, `FiM`, `AFM`, `NM`) получены из расчётной базы **Materials Project (DFT)** и являются расчётными, а не экспериментально измеренными. Оценка нетоксичности реализована строго как **rule-based фильтр** по элементному составу и степеням окисления (без обучения ML-модели токсичности).

## Методология и данные (Этап 1)

1. **Выборка (`01_data_collection.ipynb`):**
   * Выгружено 47 721 запись оксидов из Materials Project с порогом термодинамической стабильности $E_{\text{hull}} \le 0.10$ эВ/атом.
   * После удаления полиморфных дубликатов (оставлен наиболее стабильный полиморф) получено **31 282** уникальных состава.
   * Применён rule-based фильтр нетоксичности (исключены составы с `Pb`, `Cd`, `Hg`, `As`, `Tl`, `Be`, `Se`, `Sb`, `Te`, `Os`, `Ba`, радиоактивными элементами и `Cr(VI)`). Рабочая выборка составила **23 077** нетоксичных оксидов (73.8%), распределённых по **9 503** уникальным химическим системам (`chemsys`).
   * Основная целевая переменная — `target_ferro` (`FM` / `FiM` — 10 613 составов, 46.0% против `AFM` / `NM` — 12 464 составов, 54.0%).

2. **Признаки (`02_` и `03_`):**
   * **Состав:** 132 композиционных дескриптора Magpie (`matminer`, 124 неконстантных).
   * **3D-структура и кристаллохимия (17 признаков):** координационные числа катионов по кислороду, длины связей M–O и M–M, ионные радиусы, октаэдрический фактор и фактор толерантности Гольдшмидта, плотность, объём на атом.
   * **Симметрия:** номер пространственной группы (`spacegroup_number`) и сингония (`crystal_system`, one-hot).

3. **Валидация:**
   * Кросс-валидация **5-fold `GroupKFold`** по химическим семействам (`chemsys`) — все составы одного семейства попадают либо целиком в обучение, либо в тест.
   * Заполнение пропусков (`SimpleImputer(strategy="median")`) и масштабирование (`StandardScaler` для Logistic Regression) выполняются строго внутри `Pipeline` на обучающих фолдах.

## Ключевые результаты Этапа 1

### 1. Проверка утечки данных через пространственную группу (`target_ferro`)

Оценка `Random Forest` на 5-fold `GroupKFold` по `chemsys`:

| Набор признаков | ROC-AUC (5-fold GroupKFold) |
| :--- | :---: |
| Только состав (Magpie) | `0.9475 ± 0.0042` |
| Состав + 3D-структура (без симметрии) | `0.9489 ± 0.0039` |
| Состав + 3D-структура + симметрия (SG) | `0.9504 ± 0.0037` |
| Только симметрия (контрольный тест) | `0.6567` |

* Прирост от добавления пространственной группы минимален (`+0.0015`, в пределах погрешности по фолдам), а её вклад в важность признаков составляет около `1.4%`.
* Качество внутри отдельных сингоний без признаков симметрии остаётся высоким (`0.922–0.969`). **Утечки данных через пространственную группу не выявлено.**

![Проверка утечки через симметрию](figures/Magpie%20+%203D.png)

### 2. Ранжирование, эталоны и разбор ошибок (`04_ranking_and_errors.ipynb`)

* **Кристаллохимическая проверка 3D-признаков:** для эталонных шпинелей получено точное теоретическое среднее координационное число `5.333`, для октаэдрических фаз ($\text{Fe}_2\text{O}_3$, $\text{FeO}$) — `6.000`.
* **Эталонные материалы:** известные нетоксичные ферримагнетики (магнетит $\text{Fe}_3\text{O}_4$ и феррошпинели) стабильно получают высокие out-of-fold вероятности и попадают в верхнюю часть рейтинга (подробно — в `results/reference_materials_check.csv`).
* **Главная зона ошибок (`Random Forest`, `n_estimators=300`, `class_weight="balanced"`):** доля ошибок по исходным классам составила **84.1%** на антиферромагнетиках (`AFM`), **10.5%** на `FM`, **5.9%** на `FiM` и **4.9%** на `NM`. Модель уверенно отличает магнитные и немагнитные составы, но склонна относить антиферромагнитные фазы к классу `FM/FiM` из-за схожего состава переходных металлов.

## Воспроизведение

1. Клонируйте репозиторий и установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
2. Создайте локальный файл `.env` на основе `.env.example` и укажите свой ключ Materials Project:
   ```env
   MP_API_KEY=your_32_char_materials_project_api_key
   ```
3. Запускайте блокноты в папке `notebooks/` последовательно (`01_` → `02_` → `03_` → `04_`).
   * *Альтернатива:* если не нужно повторять выгрузку из API, готовые промежуточные таблицы (`oxides_dataset_v0.csv`, `oxides_features_magpie.csv`, `oxides_features_full.csv`) можно скачать из раздела **Releases** (если они прикреплены) и положить в папку `data/`.
